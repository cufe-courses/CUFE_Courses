## :material-lightbulb-on: 使用建议

!!! tip "新手入门"
    
    如果你是第一次接触这些工具，建议按照以下顺序：
    
    1. **校园网自动登录** - 解决基础网络问题
    2. **经济学 AI 使用指南** - 了解 AI 工具的基本使用
    3. **根据需求选择** - PDF 翻译、文献爬取或摘要生成

!!! info "环境准备"
    
    大部分工具需要 Python 环境和相应的 API Key。建议：
    
    - 安装 Python 3.8+
    - 准备一个大语言模型 API（如 OpenAI、Claude 等）
    - 阅读各工具的 README 了解详细配置
