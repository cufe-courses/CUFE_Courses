# PDF 论文读书笔记生成工具 (PaperDigest)

> 🔗 **GitHub 仓库**: [https://github.com/luzhiyu-econ/PaperDigest](https://github.com/luzhiyu-econ/PaperDigest)

PaperDigest 是一个基于大语言模型的 PDF 论文中文摘要生成工具，能够将任意格式的 PDF 学术论文转换为格式化的中文摘要文档。

## 主要功能

- **智能摘要生成**：自动提取论文核心内容，生成结构化中文摘要
- **多模型整合**：整合多个大语言模型的优势
- **全流程自动化**：从论文解析到 LaTeX 排版的完整流程
- **格式化输出**：输出美观的 LaTeX 格式文档

## 工作流程

```
PDF 论文 → 文本提取 → AI 分析理解 → 结构化摘要 → LaTeX 排版 → 输出文档
```

## 使用场景

- 快速了解论文主要内容
- 生成文献阅读笔记
- 辅助文献综述撰写
- 学术论文快速筛选

## 输出内容

生成的摘要文档通常包含：

- 论文基本信息（标题、作者、期刊等）
- 研究背景与动机
- 主要研究方法
- 核心发现与结论
- 研究贡献与局限

## 安装与使用

请访问 [GitHub 仓库](https://github.com/luzhiyu-econ/PaperDigest) 获取详细的安装说明和使用教程。

## 注意事项

- 需要配置大语言模型 API
- 摘要质量取决于原论文的可读性和 AI 模型能力
- 建议将 AI 生成的摘要作为参考，重要内容仍需阅读原文确认

- 需要大量阅读文献的研究生
- 进行系统性文献综述的研究人员
