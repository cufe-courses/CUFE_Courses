# PDF AI OCR 翻译工具 (PDF-Translator)

> 🔗 **GitHub 仓库**: [https://github.com/luzhiyu-econ/PDF-Translator](https://github.com/luzhiyu-econ/PDF-Translator)

该工具提供可视化界面，简化通过 pdf2zh 调用大语言模型翻译英文文献的过程。

## 主要功能

- **可视化操作界面**：简化翻译流程，无需命令行操作
- **多翻译引擎支持**：支持多种大语言模型作为翻译后端
- **OCR 识别**：支持扫描版 PDF 的文字识别
- **保持原始布局**：翻译后尽可能保持文档原有格式

## 使用场景

- 英文学术论文快速翻译
- 外文文献阅读辅助
- 扫描版 PDF 文档的文字提取与翻译

## 技术特点

- 基于 pdf2zh 项目
- 集成大语言模型 API
- 支持批量处理

## 安装与使用

请访问 [GitHub 仓库](https://github.com/luzhiyu-econ/PDF-Translator) 获取详细的安装说明和使用教程。

## 注意事项

- 使用前需要配置相应的 API Key
- 翻译质量取决于所选择的翻译模型
- 对于复杂排版的 PDF 可能需要人工调整
