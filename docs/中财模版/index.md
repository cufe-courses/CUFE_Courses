## :material-lightbulb-on: 使用建议

!!! tip "选择合适的模版"

    | 场景 | 推荐模版 |
    |------|---------|
    | 课堂汇报、小组展示 | 官方 PPT 模版 |
    | 毕业论文答辩 | 论文汇报 PPT |
    | 数学/统计类汇报 | LaTeX Beamer 模版 |
    | 毕业论文撰写 | Word/LaTeX 论文模版 |
    | 线上会议 | 腾讯会议背景 |

!!! warning "注意事项"

    - 模版仅供学习和校内使用
    - 使用 LaTeX 模版需要安装 TeX 发行版（如 TeX Live）
    - 建议保留原有格式，仅修改内容部分
