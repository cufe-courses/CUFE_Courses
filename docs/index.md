## :material-lightbulb-on: 项目初衷

!!! quote "为什么要做这个项目？"

    在课程的学习中，存在着大量的未知与难点。是否应该选这门课、课程的内容是什么、往年考试考过什么样的内容？这些问题对于一个新同学而言往往是无从得知的。
    
    如何公开分享课程信息，让自己的课程笔记发挥余热，让学弟学妹不再需要重复购买那些真假难辨的资料，这是本平台所希望解决的问题。

## :material-download: 下载方式

=== ":material-puzzle: 浏览器插件（推荐）"

    适用于只需要下载特定文件夹的用户：

    1. 安装 **GitZip** 插件：
        - [:fontawesome-brands-chrome: Chrome 插件](https://chrome.google.com/webstore/detail/gitzip-for-github/ffabmkklhbepgcgfonabamgnfafbdlkn?hl=en)
        - [:fontawesome-brands-firefox: Firefox 插件](https://addons.mozilla.org/en-US/firefox/addon/gitzip/)
    2. 在 GitHub 仓库中勾选需要的文件夹
    3. 点击下载按钮即可

    !!! warning "注意"
        需要 GitHub 账号并授权插件访问

=== ":material-web: DownGit 在线下载"

    无需登录，适合下载单个文件夹：

    1. 复制 GitHub 文件夹的网址
    2. 打开 [DownGit](https://minhaskamal.github.io/DownGit/#/home)
    3. 粘贴网址，点击 **Download** 即可

    !!! tip "提示"
        一次只能下载一个文件夹，但无需 GitHub 账号

=== ":material-git: Git Clone"

    适合需要完整仓库的用户：

    ```bash
    git clone https://github.com/cufe-courses/CUFE_Courses.git
    ```

    !!! info "说明"
        仓库较大，下载可能需要一些时间
