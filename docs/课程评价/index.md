## :material-lightbulb-on: 评价说明

!!! info "关于课程评价"

    课程评价包含以下维度的信息：
    
    - 👨‍🏫 **老师风格**：讲课方式、与学生互动情况
    - 📝 **作业情况**：作业量、作业难度
    - 📊 **考试难度**：考试形式、题目难度、是否有往年题
    - ⭐ **给分情况**：给分宽松程度、是否会捞人
    - 💡 **学习建议**：学长学姐的经验分享

!!! warning "免责声明"

    - 评价仅代表个人观点，具体情况可能因学期、班级而异
    - 请理性参考，独立判断
    - 老师名称已匿名处理（仅显示首拼）
