## :material-magnify: 快速查找

!!! tip "如何找到你需要的课程？"

    1. **使用搜索**：点击右上角搜索图标，输入课程名称
    2. **按分类浏览**：使用上方的学科分类标签页
    3. **查看侧边栏**：左侧导航栏列出了所有课程

!!! info "关于课程资料"

    - 📚 资料类型：课件PPT、习题答案、期末复习、往年试题等
    - 👨‍🏫 老师标注：括号内为授课老师首拼，如（wqz）
    - 📅 持续更新：欢迎贡献新资料
